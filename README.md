# Slimeworks Level Editor

Отдельный 3D-редактор уровней для **Slimeworks Factory**, написанный на C и raylib. Он создаёт переносимые текстовые файлы `.levl`; игра загружает их сама при старте.

## Запуск

Открой в VS Code именно папку `Slimeworks Level Editor` и нажми `F5`. Конфигурация сначала выполнит `make clean && make`, затем откроет редактор.

Из терминала:

```sh
make
./main
```

## Быстрый старт

1. В новом документе уже есть пол, старт игрока и пример цветного бокса.
2. Добавляй объекты клавишами `A`, `P`, `R` и `K`.
3. Выделяй объект мышью или `Tab`, перемещай стрелками, поднимай и опускай `Q`/`E`.
4. Нажми `Ctrl+S` — рядом с программой появится `level.levl`.
5. Нажми `F6`. Редактор экспортирует уровень в `../Slimeworks Factory/levels/factory.levl`.
6. Запусти игру. Если этот файл существует, игра загружает его вместо встроенной тестовой карты.

## Управление

| Действие | Клавиши |
| --- | --- |
| Мышь — схема Blender | MMB — orbit; `Shift` + MMB — pan; `Ctrl` + MMB — плавный dolly; колёсико — zoom |
| Тачпад — macOS и Windows | ПКМ — orbit; `Shift` + ПКМ — pan; `Ctrl` + ПКМ — плавный dolly; scroll — zoom |
| Free mode | `Shift` + `]`; удерживать ПКМ или MMB + `WASD`, `Q`/`E` и мышь; повторить `Shift` + `]` для orbit |
| Ортографический вид — macOS и Windows | `Ctrl` + `Shift` + `1` — front, `3` — right, `7` — top |
| Выделение | ЛКМ или `Tab` |
| Создать бокс / площадку / склон / маркер | `A` / `P` / `Shift` + `R` / `K` |
| Импорт модели | `I`, вставить путь, `Enter` |
| Движение | стрелки; `Q` вверх, `E` вниз; `Shift` — крупный шаг |
| Размер | `[` и `]` |
| Поворот бокса или модели | `,` и `.` |
| Gizmo | `G` движение, `R` вращение, `S` масштаб; ЛКМ перетаскивает цветную ось или кольцо |
| Apply Scale | `Ctrl`/`Cmd` + `A` для выбранной статической модели |
| Grid / snap | `Shift` + `S` включить/выключить snap; `Shift` + `,` / `.` изменить шаг сетки |
| Имя / тег | `F2` / `T` |
| Выбранная грань / следующий цвет | `F` / `C` |
| Bevel | `B` увеличить, `N` уменьшить |
| Edge loops у бокса | `+` увеличить, `-` уменьшить |
| Коллизия | `O` |
| Показать AABB коллайдеры | `H` |
| Удалить | `Delete` |
| Сохранить / загрузить | `Ctrl+S` / `Ctrl+O` |
| Экспорт в игру | `F6` |
| Новый стартовый уровень | `F1` |

## Что умеет редактор

- Боксы с отдельным цветом верхней, нижней, передней, задней, правой и левой стороны.
- Рабочий bevel и регулируемые edge loops: боковая геометрия разбивается на реальные сегменты при отрисовке и сохраняется в `.levl`.
- Навигация повторяет знакомую схему Blender для мыши; на тачпаде MMB заменяется на ПКМ без дополнительных `Option`/`Alt`-комбинаций. Есть свободный режим, ортографические front/right/top-виды, трансформационный gizmo и сетка с шагом `0.125–4` единицы.
- Вместо конечной `DrawGrid` используется прозрачная процедурная сетка: в перспективе она лежит на земле и следует за рабочей областью, а в ортографическом виде разворачивается к камере. Поверни камеру — редактор автоматически вернётся в перспективу и к наземной сетке.
- Площадки и проходимые склоны — они сразу становятся поверхностью для контроллера игрока.
- Теги для любого объекта: например `factory`, `ore_spawn`, `npc_spawn`, `quest_terminal`.
- Невидимые маркеры. В игре они не рисуются, но доступны по имени или тегу. Тег `player_spawn` задаёт точку появления игрока.
- Импорт `OBJ`, `GLB`, `GLTF`, `IQM`, `VOX`; файл копируется в `assets/` и получает автоматический AABB-коллайдер.
- `Ctrl`/`Cmd` + `A` запекает scale статичной импортированной модели в новый OBJ и сохраняет её UV и albedo-текстуры. В `.levl` после этого остаётся scale `1,1,1`, поэтому экспорт в игру не использует растягивающий transform.
- Импорт `FBX` через конвертацию в `GLB`. raylib не читает FBX напрямую, поэтому это стабильнее, чем тащить FBX-рантайм в игру. Один раз установи Assimp:

```sh
brew install assimp
```

После этого `I` + путь к `.fbx` автоматически конвертирует его в `assets/<имя>.glb`.

## Теги в коде игры

Парсер добавил удобные запросы в `src/world/level.h`:

```c
Vector3 oreSpawns[16];
int count = LevelFindMarkersWithTag(&game->level, "ore_spawn", oreSpawns, 16);

const LevelModel *terminal = LevelFindModel(&game->level, "quest_terminal");
```

Так точки спавна и импортированные props не привязаны к координатам, захардкоженным в игровом коде.

Полная спецификация файла: [LEVEL_FORMAT.md](LEVEL_FORMAT.md).
